# Student Grade Management System

## Project Description

This project is a student grade management program. It shows how Python can be used to enter, store, calculate, display, update, search and manage student grades.

The project is divided into two Python files:

* `section A+B.py`

* `section c.py`

---------------------------------------

## Section A+B

The `section A+B.py` file contains 
Section A and Section B of the project.

### Section A: Student Data Entry and Grade Calculation

Section A allows the user to:

* Enter the number of students.

* Enter a students name.

* Enter the students grade.

* Check whether a grade is between 0 and 100.

* Calculate the total of the grades.

* Calculate the grade.

The program uses a while loop to ensure that an invalid grade is not accepted.

### Section B: Lists and Tuples

Section B expands the program by using lists and tuples.

The program:

* Creates a list to store students.

* Creates lists for IDA, Python and DDD grades.

* Accepts grades for the three subjects.

* Validates each grade.

* Stores the three grades in a list.

* Stores the students name and grades together in a tuple.

* Adds each student to the students list.

* Calculates each students average.

* Finds the lowest grade for each subject.

-------------------------------------

## Section C: Dictionaries

The `section c.py` file uses dictionaries to store and manage student information.

The students name is used as the key while the students grades are stored as the value.

MAIN FEATURES 

The program allows the user to:

1. Add students

* Enter the number of students.

* Enter each students name.

* Enter IDA, Python and DDD grades.

* Prevent duplicate student names.

* Validate grades between 0 and 100.

2. Display all students

* Display each students name.

* Display their IDA, Python and DDD grades.

*. Display their average.

3. Update student grades

* Search for an existing student.

* Enter grades.

* Update the students stored grades.

4. Remove a student

* Search for a student.

* Delete the students record if they exist.

5. View grades for a subject

* Select IDA, Python or DDD.

* Display the grades stored for that subject.

6. Search for a student

* Enter a students name.

* Display their grades. Average if they are found.
